      ФИКС: восстановлена ванильная схема матриц. ModelNpcAlt/ModelBipedAlt/
      ModelBipedAW.render обёрнуты в push/pop, sneak-сдвиг +0.2 внутри
      (утечки в слои устранены). Удалены все ручные компенсации: -0.2 в

[003] ✅ (нужна проверка в игре) Вращение частей тела интерполируется не по
      кратчайшему пути через 0: поворот 340 -> 30 происходит как
      340 -> 180 -> 30 вместо 340 -> 360/0 -> 30.
      ФИКС: причина — clamp вместо wrap. PartConfig.load обрезал углы из NBT
      до ±PI (340°->180°), API setRotation искажал через "%= 180" (340°->160°),
      интерполированные значения вне ±PI утекали в preFrame без нормализации.
      Добавлены ValueUtil.wrapFloat/wrapRadians; wrap в PartConfig.load/
      setRotation/set, нормализация входов интерполяции в
      CustomAnimationHandler; в CustomEmotionHandler добавлена отсутствовавшая
      shortest-path коррекция (градусы, порог 180); в JobPuppet.calcRotation
      добавлен wrap (углы 0-360 из GUI, lerp шёл длинным путём).

[004] ✅ (нужна проверка в игре) Субгуи выбора текстуры: модель NPC смещена
      вправо, должна быть по центру.
      ФИКС: в SubGuiTextureSelection.drawScreen превью NPC рисовалось на
      захардкоженном X=312, центр квадрата превью = 306 (266 + 80/2).

[005] ✅ (нужна проверка в игре) Изображения (в GUI) отображаются корректно

      ФИКС: картинки диалогов (GuiDialogInteract). Поле DialogTexture.left
      заполнялось только когда якорная строка картинки попадала в видимое
      окно (~15-17 строк, окно прижато к низу лога), иначе left=0 и гейт
      "left < guiLeft -> continue" полностью скрывал картинку даже при
      прокрутке вверх. Теперь left вычисляется при каждом рендере,
      видимость определяется штатной проверкой попадания строки в окно.

[006] ✅ (нужна проверка в игре) Нет опции отключения панорамы главного меню,
      добавляемой модом.
      ФИКС: опция уже существовала (ReplaceCustomBackground в категории client
      конфига), но работала не полностью: mixin GuiMainMenuMixin безусловно
      отменял ванильные renderSkybox/drawPanorama/rotateAndBlurSkybox, поэтому
      даже при false рендер шёл кастомным кодом без ванильного blur. Теперь
      при ReplaceCustomBackground=false все инъекции отдают управление
      ванильному коду (панорама и размытие полностью ванильные).

[007] ✅ Опечатка в английском описании кнопки фракции в продвинутых настройках.
      ФИКС: en_us.lang:1287 "global.factions=Fractions" -> "Factions".
      Ключ виден в хинте сортировки выбора фракции (Advanced -> Faction ->
      выбор) и в заголовке списка фракций на вкладке Global.

[008] ✅ (нужна проверка в игре) Копирование анимаций не работает.
      ФИКС (4 причины):
      1) getUnusedAnimId возвращал занятый id (break на первом ключе TreeMap
         при baseMaxAnimID>0) — копия перезаписывала существующую анимацию;
         аналогично исправлен getUnusedEmtnId;
      2) кнопка Copy создавала копию только в клиентском контроллере — теперь
         шлёт SPacketAnimationChange(2)+(3) на сервер; копия получает
         уникальное имя (имя_id); удаление тоже шлёт (1);
      3) все SPacketAnimation* в GuiNpcAnimation/SubGuiEditAnimation
         отправлялись через Packets.sendAll (сервер->клиенты) вместо
         sendServer — серверные обработчики никогда не выполнялись, правки
         анимаций и привязка к NPC не сохранялись (8 вызовов исправлено);
      4) вставка копии кадра в конец (Shift+добавить): NPE в addFrame при
         frameId==size (молча глотался) + диалог не давал ввести позицию
         "за последним кадром".

[009] ✅ (нужна проверка в игре) Анимации не переносятся из одного мира
      в другой.
      ФИКС (2 причины):
      1) NPC/клон хранил в NBT только ID анимаций, сами данные лежат в
         per-world папке (saves/<мир>/customnpcs/animations) — в другом
         мире ID указывали в пустоту. Теперь CustomAnimationHandler.save
         дописывает в NBT сущности полные данные используемых анимаций
         (тег AllAnimationsData), а load при отсутствии анимации в мире
         создаёт её с новым id (ремап по всем спискам, включая
         MovementAnimations) — клоны переносятся между мирами/серверами;
      2) миграция старых глобальных анимаций (customnpcs/animations в
         корне игры) была деструктивной: первый открытый мир забирал их
         себе и УДАЛЯЛ глобальную папку — остальные миры оставались без
         анимаций. Удаление убрано, папка теперь сохраняется и подгружается
         в каждый мир.
      Попутно: исправлен NPE в ветке конвертации старого формата и
      неверный тип пакета (анимация уходила клиентам как эмоция).
